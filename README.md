Python 42 Modules (python00 – python10)
A 42-style Python curriculum: eleven modules covering the language from first
`print` to data validation, decorators, and environment management.
```
python00/  Basics
python01/  Basic types & data structures
python02/  Exceptions
python03/  Modules
python04/  File handling
python05/  OOP — abstract classes & inheritance
python06/  Packages & import structures
python07/  Design patterns
python08/  Environments & dependencies
python09/  Data validation with Pydantic
python10/  Functional programming tools
```
Notes
No tests are included; exercises are meant to be run by hand and observed as a guide. I don't condone copying and pasting as your own code, take your time to understand
the subject sheet and the concepts.
